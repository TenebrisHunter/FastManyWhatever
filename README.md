# FileSmith (working title)

> Простой инструмент для массового создания и переименования файлов
> и папок — по правилу или по списку, без регулярок и командной строки.

---

## 💡 Идея

Пользователь приходит с одной из двух задач:

1. **Правило (цикл):** «создай мне Задание 1 … Задание N»
   или «переименуй part-1 … part-39 по шаблону `027-{i}_...`».
2. **Список (таблица):** «вот 39 названий — создай по папке на каждое»
   или «вот соответствия старых имён новым — переименуй».

На практике это часто **гибрид**: цикл по номерам + подстановка строк
из списка. Существующие инструменты закрывают эти сценарии по
отдельности, но не вместе и не с простым интерфейсом.

**Цель:** одно окно, два режима на входе, предпросмотр и одна кнопка
«Создать». Порог входа — нулевой: человек, никогда не открывавший
терминал, справляется за минуту.

---

## 🔥 Проблема, которую решаем

Сейчас, чтобы создать 39 папок по списку из Excel, человек:

- либо теряется в `Bulk Rename Utility` / `Advanced Renamer`;
- либо пишет формулу в Excel → копирует в блокнот → сохраняет `.bat`
  → запускает и молится, чтобы кириллица не сломалась;
- либо ищет онлайн-генератор и всё равно запускает результат вручную.

То есть люди **уже собирают этот комбайн вручную каждый раз**.
Мы просто упаковываем стихийный workflow в нормальный интерфейс.

## 🧱 Ключевые фичи (v1.0)

### Режим «Список»
- [ ] Большое текстовое поле: «вставь строки — каждая строка = папка/файл».
- [ ] Импорт из `.txt` / `.csv` (выбор колонки).
- [ ] Чекбокс «добавить нумерацию»: `начать с`, `шаг`, `формат` (`1`, `01`, `001`).

### Режим «Правило»
- [ ] Поля: `Префикс` + `Счётчик от_до` + `Суффикс` + `Расширение`.
- [ ] Живой предпросмотр: `Задание 1.txt`, `Задание 2.txt`…

### Общее
- [ ] **Предпросмотр** списка до выполнения (таблица «что будет создано»).
- [ ] Выбор: создавать **папки** или **файлы**.
- [ ] Одна кнопка **«Создать»**.
- [ ] Лог результата + возможность откатить (сохранить лог в файл).
- [ ] Проверка на недопустимые символы (`\ / : * ? " < > |`) с предупреждением.
- [ ] Обработка конфликтов: «уже существует» → пропустить / перезаписать / переименовать.
- [ ] UTF-8 по умолчанию, корректная работа с кириллицей и кавычками.

## 🎯 MVP (минимально жизнеспособная версия)

> Вставь список строк → выбери: создать папки или файлы →
> задай префикс / суффикс / расширение / нумерацию →
> посмотри предпросмотр → нажми «Создать».

Без импорта Excel, без регулярок, без шаблонизации содержимого.
Только **имена**. Этого хватит, чтобы закрыть 80% бытовых задач
и проверить, нужен ли инструмент людям.

## 🛠 Технологический стек (предложение)

- **Кроссплатформенный GUI:** Tauri (Rust + web) или Electron
  — один код на Windows / macOS / Linux.
- **Альтернатива для быстрого старта:** Python + PyQt / Tkinter.
- **Только Windows:** WPF / WinForms (но тогда отсекаем macOS/Linux).

## 🔗 Референсы и вдохновение

- `Bulk Rename Utility` — мощь, но перегруженный интерфейс.
- `PowerRename` (PowerToys) — хороший UX, но только переименование.
- `Advanced Renamer` — регулярки и правила.
- `file-grid`, `tempren` — CLI-шаблонизация.
- `spawn-files` — создание из списка.
- `Giter8` — генерация структуры проекта по шаблону.
- `Folder Creator X` — импорт имён из Excel/CSV.
- `Folder Tree Creator` — визуальное построение дерева.
